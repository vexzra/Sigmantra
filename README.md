# Sigmantra

> **Simple. Rápida. Gratis para siempre.**

Sigmantra es una aplicación minimalista para organizar **hábitos** y **tareas diarias** mediante listas de verificación (checklists), diseñada para quienes solo quieren abrir la app, marcar lo que hicieron y continuar con su día.

Sin publicidad. Sin suscripciones. Sin complicaciones.

---

## ✨ Características

- ✅ Checklist de tareas diarias
- 🌱 Seguimiento de hábitos
- ⚡ Interfaz simple y rápida
- 📱 Fácil de usar
- 🌙 Diseño limpio y minimalista
- 💾 Guarda tus datos de forma local
- 🚫 Sin anuncios
- 💸 Gratis para siempre

---

## 🎯 Filosofía

Hoy en día existen muchas aplicaciones para productividad que terminan siendo complejas, llenas de publicidad o con funciones bloqueadas detrás de una suscripción.

**Sigmantra** nace de una idea muy simple:

> *Todo el mundo debería poder llevar un registro de sus hábitos y tareas sin anuncios, sin interrupciones y sin pagar.*

La aplicación busca ofrecer únicamente lo esencial, eliminando todo aquello que distrae.

---

## 🚀 Objetivo

Crear una herramienta que permita:

- Mantener hábitos saludables.
- Organizar tareas diarias.
- Mejorar la productividad.
- Hacer seguimiento del progreso.
- Mantener una experiencia limpia y rápida.

## ❤️ Siempre gratis

Sigmantra está comprometida con una filosofía sencilla:

- ❌ Sin suscripciones
